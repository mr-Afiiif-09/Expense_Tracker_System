# Expense Tracker System

A Python-based command-line interface (CLI) application designed to help users track personal finances, log daily expenses, monitor spending habits, and manage budgets efficiently.

## Features

- **Add Expenses**: Log new expenditures with details such as amount, category, and date/description.
- **View Records**: Browse past transactions and view total expenditure summaries.
- **Categorization**: Organize expenses into categories (e.g., Food, Travel, Utilities, Entertainment).
- **Data Persistence**: Automatically reads and saves transaction history locally (JSON/CSV).
- **Interactive CLI**: Clean, intuitive menu-driven interface for straightforward navigation.

## Tech Stack

- **Language**: Python 3
- **Libraries Used**: Built-in Python modules (`json`, `csv`, `datetime`, etc.)
